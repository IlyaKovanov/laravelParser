## О проекте

Парсер сайтов многопользовательский проект, предназначенный для сканирования страниц сайта и парсинга данных. Возможности которые предоставляет парсер:

- Парсинг ссылок каталога.
- Парсинг по ссылкам заданным вручную.
- Парсинг изображений.
- Сохранение результатов в форматы csv, xlsx или вывод результата на экран.

## Настройки проекта

### Добавление/редактирование проекта
В настройках проекта необходимо указать: 

- Project name - название проекта;
- Base url - адрес сайта с https://
- Project description - краткое описание проекта которое будет отображаться на странице списка проектов;
- Заполнить блок селекторов контента для парсинга;
- Выбрать формат сохранения.

### Блок селекторов контента для парсинга
- **Title** - заголовок столбца таблицы, например Название или Цена
- **Selector** - идентификатор DOM элемента .selector или #selector
- **Selector type** - text - текстовое значение, например Название, multiple - список, например Характеристики, image - изображение;
